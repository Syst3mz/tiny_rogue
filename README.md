A quick and dirty not very good clone of the game that started the Roguelike trend, Rogue! It's implemented in rust and for the Playdate handheld console. Building for playdate is a...work in progress, but it does work on the windows simulator. If you have rust, rust nightly, and cargo [playdate](https://github.com/boozook/playdate) installed, along with the ARM ABI you should be able to compile to your host OS's version of the Playdate Simulator.
